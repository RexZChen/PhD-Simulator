# Progression audit — 2026-09-25

This is automated progression evidence, not a claim that the game is ready to release.

## Fixed: a failed defense never reconvened

A first failed defense sets `milestones.defense` to `revisions` and schedules a new defense three months later. `milestoneOf()` previously required an empty defense result, so it ignored that new date. The calendar never convened the committee again and a player could reach the funding deadline with no way to graduate.

The calendar now treats `revisions` as an outstanding defense. `tests/progression.test.js` exercises the actual milestone and viva result actions: the first failure, the repeat date, season-pace protection, the second room, and the deposit checklist. A second test verifies that a repeat defense in the final funding month reaches commencement through the existing deferred-deposit route. The first test failed before the fix (`milestoneOf()` returned null) and both pass afterward.

## Fixed: the reach report omitted career endings

`trackEndings` is a keyed record, but the reach script read nonexistent `id` properties from its values. All twelve career endings collapsed into a single undefined entry. The script now uses the actual `phd_` ending IDs and also includes endings generated by program progression, including ABD and undeposited.

## Measurements

`npm run reach` played 90 runs: 328 of 358 events, 69 of 118 achievements, and 15 of 30 endings were reached. It exits 1 because there are still coverage gaps. No `stuck` ending appeared. Patent decisions and hard TA assignments were reached; spinout ventures were not.

An isolated comparison ran the same 40 seeds in each of three styles with only the defense eligibility fix changed. Diligent and grinder ending distributions were unchanged. Lazy changed from two ABD runs to one additional industry-research ending and one additional unplaced PhD ending. This verifies that real scripted runs benefited from the repair; it does not establish overall game balance.

## Still to investigate

- All six review scenes were unseen. The scripted strategies answer rebuttals and recycle rejected papers immediately, and eligibility binds paper conditions to the active project. Dedicated review controls work, but optional paper stories may be too easy to miss after switching projects.
- Several missing events are choice-dependent follow-ups (`tax_letter`, `cpt_late`, `visa_scramble`); the harness always chooses an earlier alternative. Missing coverage alone is not proof these are broken.
- `conference_travel` is a fallback event replaced by the dedicated trip flow when the game's conference hook is installed. Its absence should not be interpreted as absent conference gameplay.
- The harness does not play optional desk interactions, detailed timed-viva gestures, or every exit choice, so their achievements and endings need separate scenario coverage.
- A first defense delayed until the final funding month can still fail without enough time to retry. That deadline behavior needs an explicit design decision and a player-facing explanation; this fix does not extend the six-year limit.

The full unit suite passed with the first regression included (134 tests); the subsequently added final-month regression also passes independently. Browser, translation, and final combined-suite verification are recorded by the parent release pass.
